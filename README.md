# ChessSaiFare

A chess learning site with an AI teacher. This repository holds the code.

Status: prototype. The prototype is a single HTML page in [`prototipo/`](prototipo/).

## Run the prototype

```bash
cd prototipo
npm ci
npm test
node build.js
```

`node build.js` writes `prototipo/dist/index.html`. Open it in a browser.

The public repository includes sample lessons only. The full content lives in a separate private repository.
